                    VALIDEXIO SYSTEM ARCHITECTURE & FILE MAP

This index maps out all pages of the Validexio application to their page files,
associated components, helpers, and backend API routes. Use this to quickly
locate files for debugging or logic review.

────────────────────────────────────────────────────────────────────────────────
1. MAIN LANDING PAGE (/)
────────────────────────────────────────────────────────────────────────────────
* Main Page File:
  - app/page.tsx
* Client components used:
  - components/RuthlessStats.tsx (Reject vs green light statistical card)
  - components/CompetitorComparison.tsx (Feature comparison grid)
  - components/SecureCheckoutBadge.tsx (SSL and secure payment badge)
  - components/marketing/GlobalCompetitorsGlobe.tsx (Interactive globe widget)
  - components/layout/Navbar.tsx (Navigation bar and mobile drawer)
* Custom Hooks & Data:
  - hooks/useCurrency.ts (Dynamic geolocation-based INR/USD pricing switcher)
  - lib/blog-data.ts (Holds static text and static mock blog article inputs)

────────────────────────────────────────────────────────────────────────────────
2. DASHBOARD SHELL & HOME (/dashboard)
────────────────────────────────────────────────────────────────────────────────
* Main Page File:
  - app/dashboard/page.tsx (Calculates user stats, validation reports lists)
* Client components used:
  - components/layout/Navbar.tsx (Shared header)
  - NextJS TopLoader progress bars
* Layout & Middleware Guards:
  - app/dashboard/layout.tsx (Implements authentication gate checks)
  - lib/guards/ (Helper guards for active user status validation)

────────────────────────────────────────────────────────────────────────────────
3. VALIDATION FORM / STARTUP IDEAS GENERATOR (/dashboard/validate)
────────────────────────────────────────────────────────────────────────────────
* Main Page File:
  - app/dashboard/validate/page.tsx (Multi-step validation wizard form)
* Loading State Page:
  - app/dashboard/validate/loading.tsx
* Components & Inputs:
  - components/ui/SearchableSelect.tsx (Custom selector component with filters)
  - components/CookieConsent.tsx (CookieConsentModal to intercept and block clicks)
* Core Logic & API Routes:
  - app/api/validate/route.ts (Accepts form post, executes Prisma db atomic transaction)
  - app/api/generate/route.ts (Background job dispatcher - handles BullMQ queue)
  - lib/queue/processJob.ts (Background worker main thread. Coordinates APIs:
    Tavily, SerpApi, HackerNews, Reddit, Wikipedia, Mockups, and Gemini)
  - lib/gemini.ts (Handles GoogleGenAI gemini-3.5-flash and fallback model schemas)
